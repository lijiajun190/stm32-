## ⚠️ 冲突与调整说明

### 已解决的冲突

1. **PA0按键冲突**
   - 问题：PA0原计划ADC，但板载已用作按键
   - 解决：MQ-135改用PA4（ADC1_IN4），PA0复用为编码器按键

2. **TIM2编码器与PWM冲突**
   - 问题：TIM2设为编码器模式后Channel2无法用PWM
   - 解决：电机PWM改用TIM1_CH3N（PB15）

3. **I2C2_SDA引脚不支持**
   - 问题：PC11不是I2C2的有效引脚
   - 解决：改用PB3（I2C2_SDA的标准引脚）

4. **RGB LED冲突**
   - 问题：PB15已用于电机PWM，无法作为蓝色LED
   - 解决：改为RG双色LED（PB12+PB14），蓝色用板载LED(PC13)

### 不可用的功能

❌ **WiFi模块（ESP8266）**
- 原因：UART2(PA2/PA3)与编码器引脚冲突
- 备选：后续可用USART6或软串口实现

❌ **SPI Flash存储**
- 原因：板载SPI已被LCD占用
- 备选：使用I2C EEPROM（AT24C256）或内部Flash

❌ **RGB LED呼吸灯**
- 原因：PB15被电机PWM占用，且PB12不支持PWM
- 备选：简化为开关控制，或软件PWM

## 📌 连接参考

### 传感器连接

**MQ-135气体传感器：**
```
VCC  → 5V
GND  → GND
AOUT → PA4（ADC采集）
DOUT → 不接
```

**SHT30温湿度传感器：**
```
VCC → 3.3V
GND → GND
SCL → PB8 (I2C1_SCL) + 4.7kΩ上拉
SDA → PB9 (I2C1_SDA) + 4.7kΩ上拉
```

**BMP280气压传感器：**
```
VCC → 3.3V
GND → GND
SCL → PB8 (I2C1_SCL，与SHT30共享)
SDA → PB9 (I2C1_SDA，与SHT30共享)
SDO → GND (地址设为0x76)
CSB → 3.3V (I2C模式)
```

**光电测速传感器（ITR20001）：**
```
VCC → 5V
GND → GND
OUT → PA6 (上拉到3.3V，串联1kΩ电阻保护)
```

### 执行器连接

**BTS7960电机驱动：**
```
VCC   → 12V
GND   → GND
RPWM  → PB15 (TIM1_CH3N PWM)
LPWM  → GND (单向控制)
R_EN  → PC7 (电机使能)
L_EN  → GND
R_IS  → 不接（可选电流检测）
L_IS  → 不接
M+    → 电机正极
M-    → 电机负极
```

**OLED显示屏：**
```
VCC → 3.3V
GND → GND
SCL → PB10 (I2C2_SCL) + 4.7kΩ上拉
SDA → PB3 (I2C2_SDA) + 4.7kΩ上拉
```

**按键连接：**
```
PA0 (编码器按键) ─┬─ 按键 ─ GND
                  └─ 10kΩ上拉 ─ 3.3V

PC2/PC3/PC4 (功能键) ─┬─ 按键 ─ 3.3V
                    └─ 下拉电阻 ─ GND
```

**蜂鸣器：**
```
PC6 ─┬─ 1kΩ限流电阻 ─ 蜂鸣器+ ─ 5V
     └─ GND
```

## 📝 备注

1. **上拉电阻**：所有I2C总线必须有4.7kΩ上拉到3.3V
2. **按键消抖**：软件20ms消抖，或硬件加100nF电容
3. **电机隔离**：电机电源与MCU电源分开，共地
4. **电源滤波**：每个芯片靠近引脚放置100nF+10uF电容
5. **测试顺序**：LED → UART → ADC → I2C → 定时器 → 完整系统
