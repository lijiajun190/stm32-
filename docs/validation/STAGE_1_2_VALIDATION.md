# 统一启动入口与测速链路验证

本次对应截图中的第 1、2 项。应用从 `main.c` 依次调用 `App_Init()`、
`Tasks_Init()`、`App_Start()`，随后启动 FreeRTOS；不创建 CubeMX defaultTask。
任务和队列创建失败时不启动调度器，保持电机使能关闭。

## 已实现内容

- `App_Init()` 初始化 BSP、OLED、按键、TIM4 编码器、电机、ADC DMA、
  MQ135、风速传感器、SHT30、BMP280、状态机和 TIM3 测速。
- OLED、SHT30、BMP280 不可用时报告初始化失败并允许降级启动。
  ADC、编码器、测速启动失败则报告必需外设初始化失败。
- 电机控制任务每 50 ms 获取测速快照；日志任务每 1000 ms 输出快照。
  无效测速时周期、频率和 RPM 均返回 0，`valid=0`。
- TIM3 更新中断累计溢出次数，输入捕获回调保存周期和毫秒时间戳，
  单位换算在任务中执行。支持多次 16 位溢出和扩展计数回绕。
- 超时后首个脉冲只建立基准，第二个完整周期才恢复 `valid=1`。
  检测 CC1 过捕获时本次读数无效，重新建立测量基准。
- 开环命令队列只保留最新占空比；上电默认电机关闭。
- PB15 使用 TIM1_CH3N；运行时在 CubeMX USER CODE 中修正互补极性，
  高电平占空比为 `CCR3/(ARR+1)`。占空比 1000 对应 `CCR3=1000`。

传感器周期采集、数据层、PID、自动模式、故障状态机业务和看门狗喂狗
属于后续开发阶段；本次只保留对应任务入口。

## 参数与公式

`BSP/Inc/bsp_timer.h` 中配置：

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `BSP_SPEED_PULSES_PER_REV` | 1 | 必须按实际光电码盘每转脉冲数修改 |
| `BSP_SPEED_SIGNAL_TIMEOUT_MS` | 1000 | 从最后脉冲起 1000 ms 未收到脉冲时无效 |

`timer_tick_hz = TIM3_clock / (PSC+1)`，当前是 1 MHz。
APB1 分频不为 1 时，TIM3_clock 为 PCLK1 的两倍。
`frequency_hz = timer_tick_hz / period_ticks`。
`RPM = timer_tick_hz × 60 / (period_ticks × pulses_per_rev)`。
RPM 使用 64 位中间计算并取整数部分，不先截断脉冲频率。
可测最低频率受超时参数限制：脉冲间隔必须严格小于该超时值。

## 主机测试

在项目目录运行：

```powershell
./tests/run_host_tests.ps1
```

测试直接编译正式 `bsp_timer.c`、`bsp_pwm.c` 和 `motor.c`，使用 HAL 替身。
分别验证每转 1、2 脉冲：首脉冲、正常周期、非整数频率、一次及多次溢出、
溢出与捕获同时挂起的两种顺序、超时边界及恢复、过捕获、零周期、
32 位计数回绕、停止/重启/启动失败、APB1 时钟、PWM 边界和电机使能。
这些测试验证计算和软件状态，不能代替硬件波形验收。

## 上板验证

1. 下载 `firmware/build/Debug/stm32-2.elf`，USART1 使用 115200 波特率。
   查看一次初始化日志、六个应用任务创建成功，电机默认关闭。
   OLED 显示启动完成；断开 OLED 后重新上电应报告失败并继续运行。
2. 向 PA6 输入 50 Hz 的 3.3 V 脉冲信号。每转 1 脉冲时，应得到
   `period=20000`、`freq=50.000Hz`、`rpm=3000`、`valid=1`。
   输入 5 Hz 时应得到 `period=200000`、`rpm=300`，用于验证多次溢出。
3. 停止脉冲。1 秒后测速接口返回 0 且 `valid=0`；日志任务下一周期输出该状态。
   恢复脉冲后必须收到两次边沿，测速才恢复有效。
4. 需要电机开环验证时，在任务上下文显式调用固定档位接口：

   ```c
   Tasks_SetMotorDuty(250);  // 25%，由电机任务执行
   Tasks_SetMotorDuty(0);    // 关闭使能和 PWM
   ```

   第 1、2 项完成时未绑定输入；第 3、4 项已增加开环按键验证入口，
   PC2/PC3/PC4 选 30/60/100%，PA0 停机。详见 `STAGE_3_4_VALIDATION.md`。
   最小启动占空比由实际电机测定；代码不臆定该阈值。
5. 先确认驱动实物与文档的 PC7 高电平使能、PC9 低电平默认方向一致。
   示波器确认 PB15 为 20 kHz，25%/50%/100% 指令对应预期高电平比例，
   占空比为 0 时 PC7 为低电平。最后记录连续运行 5 分钟的串口与波形。
