# 阶段 5、6：传感器数据流和手动/自动闭环

日期：2026-10-04。记录软件验证结果；尚未上板，不代表实际转速精度或保护时间已验收。

## 实现范围

- SensorTask 每 100 ms 获取 ADC 最新四通道副本，更新 MQ135/风速，读取 SHT30/BMP280。
- `SensorData_t` 包含原始 ADC、电压、温湿度、原始保护温度、气压、气体电阻/比值、风速、时间戳、有效/错误标志。
- 快照队列长度为 1，overwrite/peek 不积压；系统管理与电机任务只读队列快照。
- 有效采样使用 alpha=0.2 EMA，失败后清除滤波历史，恢复首样本直接初始化。
- SHT30 采用无 clock stretching 的两阶段读取，等待 20 ms 时让出 CPU、释放 I2C1 锁。
- SHT30 校验两组 CRC；BMP280 检查芯片 ID、NVM 校准参数、跳过测量标记和范围，补偿采用 Bosch 浮点公式。
- SHT30 每周期重读；BMP280 断线后每 5 s 重试初始化，事务使用 5 ms 超时，复位等待运行时使用 RTOS delay。
- ADC 检查 HAL 错误、DMA stream 是否启用；关闭无需使用的高频 DMA HT/TC 中断。快照是逐通道最新读数，连续 DMA 下不保证四通道来自同一扫描周期。
- MQ135 预热 60 s；输出电压趋势与未校准标志，不把简化公式当作 ppm。电阻模型暂假设 VCC=5 V、RL=10 kOhm、无分压，实际模块需据接线校正；`MQ135_Calibrate()` 只校准 Rs/R0，不校准气种曲线。
- MotorTask 每 50 ms 执行 PID，dt 使用该任务实际 HAL 时间差；非法/延迟超过 150 ms 停机。PID 有输出限幅、条件积分抗饱和、微分低通和首帧抑制。
- 状态机由 SysMgr 独占写入，UI 输入使用有类型事件队列；MotorTask 是唯一电机写入者。
- 自动需求使用有效滤波电压趋势、低风速和温度，每个 100 ms 管理周期目标最多变动 50 RPM。
- OLED 显示模式、设定/实际 RPM、反馈有效和故障位；每 100 ms 发一页，一屏最多约 800 ms。I2C2 和 I2C1 使用独立锁；显示出错停止刷新，不阻塞控制任务。
- Logger 每秒统一打印 SPEED、CONTROL、SENSOR，无浮点 printf 依赖。

## 正常固件操作

1. 上电待机，电机关闭。
2. PC2 短按：STANDBY -> MANUAL -> AUTO -> STANDBY；切换模式先停机。
3. MANUAL 中 PC3/PC4 短按和编码器改变手动设定，默认 600 RPM，每档 100 RPM；编码器每 4 计数一档，需实测实际机械编码器。
4. PA0 短按释放：在 MANUAL/AUTO 中启停。调目标不会隐式启动。
5. PC2 或 PC4 长按：停机；PA0 长按：停机并申请故障复位。
6. 复位要求当前温度低于 70 C，温度数据有效/新鲜且实际 RPM <100；无测速时停机至少 2 s。复位成功回 STANDBY，不自动启动；气体/风速故障恢复仍须在再次选择 AUTO 前修复。

手动运行要求有效 SHT30，保留过温保护；MQ135 预热、风速或 BMP280 缺失只显示降级。
自动运行要求 MQ135 电压、风速、SHT30 有效，BMP280 气压为可选显示数据。

## 集中参数与故障

参数在 `Application/control_config.h`，测速 PPR 在 `BSP/Inc/bsp_timer.h`。以下全是待上板整定初值：

| 参数 | 初值 |
| --- | --- |
| 手动/自动目标范围 | 300..1800 RPM |
| 超速阈值 | >2200 RPM |
| 正常 PWM 范围 | 10..80% |
| 启动占空比/宽限 | 30%、最多 2 s |
| 低速堵转 | 启动宽限后 <80 RPM 持续 1.5 s |
| 传感器/目标命令过期 | >500 ms |
| 过温保护/恢复 | >=80 C / <70 C |
| PID Kp/Ki/Kd | 0.25 / 0.20 / 0 |

启动限时开环用于取得测速脉冲，获得有效反馈后丢失即停机；输入捕获本身的无脉冲失效阈值为 1000 ms，所以停机时间包含捕获超时与下一次电机任务周期。软件周期保护不替代后续独立看门狗。

| 故障位 | 含义 |
| --- | --- |
| 0x01 | 持续低速堵转 |
| 0x02 | 超速 |
| 0x04 | 启动无反馈/运行中反馈丢失 |
| 0x08 | 必要传感器失效或过期 |
| 0x10 | 最新未滤波温度过高 |
| 0x20 | PWM 启动失败 |
| 0x40 | 命令过期或目标越界 |
| 0x80 | 控制任务间隔异常 |

正常固件拒绝非零 `Tasks_SetMotorDuty()` 和 `Tasks_StartOpenLoopSweep()`，`duty=0` 仍可请求停机。
阶段 4 的专用开环验证需同时启用 `APP_ENABLE_OPEN_LOOP_TESTS=1` 和 `APP_OPEN_LOOP_BUTTON_CONTROL=1`；该固件用于固定占空比测试，保留超速和过温保护，不用于 PID/自动运行验收。

## 软件验证

命令：`tests/run_host_tests.ps1`，使用已有 LCC64 编译真实算法/组件/BSP 和 HAL/I2C 替身。

- GPIO/按键/开环序列：112 项。
- 输入捕获/PWM/电机，PPR=1 和 PPR=2：各 67 项。
- PID/状态机/滤波/安全：275 项，覆盖启停、模式切换同批输入不能覆盖停机、目标改变不延长启动宽限、反馈丢失、堵转恢复与锁存、超速/过温、传感器和命令过期、任务超时、32 位时钟回绕、抗积分饱和、人工复位、自动目标限速。
- 传感器：73 项，覆盖预热边界、未校准与比值、风速边界、SHT30 两组 CRC/断线/越界、BMP280 数据手册参考值和无效校准/断线。
- 总计 594 项通过。主机验证不包含实际 RTOS 调度/传感器电气故障/PWM 波形。
- Debug 固件最终构建通过，无编译警告/错误；RAM 26216 B、FLASH 71376 B。
