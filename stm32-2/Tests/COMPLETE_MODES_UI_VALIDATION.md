# 完整模式与人机交互验收

## 已实现行为

| 状态 | 进入与运行 | 退出 |
| --- | --- | --- |
| STANDBY | 上电、复位成功、限时运行结束；电机关闭 | PC2 选择 MANUAL；5 分钟无操作进入 SLEEP |
| MANUAL | PC2 选择；PA0 短按显式启动，使用手动目标 | PC2 进入 AUTO 并停机；PA0 请求延时关机 |
| AUTO | PC2 选择；PA0 显式启动，使用有效的气体/风速/温度快照 | PC2 进入 BOOST 并停机；传感器失效锁存故障 |
| BOOST | PC2 选择；PA0 显式启动，使用配置的 max_rpm | 最长 180 秒后关闭电机并回待机；PC2 进入 CLEANING |
| CLEANING | PC2 选择；目标始终为 0，启停和调速不能启动电机 | PC2 进入 SLEEP |
| SLEEP | PC2 选择或待机超时；电机关闭，OLED 关闭，保留慢心跳 | 首次普通按键/编码器动作只回待机，不启动 |
| ERROR | 电机任务发布锁存故障；立即停止并显示原因 | 长按 PA0 申请复位，必须通过电机任务的安全条件检查 |

睡眠是应用待机状态，不是 MCU STOP 低功耗模式。监控、传感器和看门狗继续运行。
清洁是现有硬件支持的停机维护状态，没有清洗泵或加热器控制。屏幕提示等风机停止，实际拆洗前必须断电。

普通 PA0 关机默认继续按当前目标排烟 30 秒，再回待机；再次短按取消倒计时。
`shutdown_delay_ms` 可在设置页修改为 0..600 秒，步长 10 秒，0 表示立即停止。
模式切换、进入设置页、长按停机、配置应用、故障和爆炒总时限均覆盖余烟排风。
所有时间使用无符号毫秒差值，支持 HAL tick 回绕。

旧 Flash 配置中的延时值为 0 时保持立即停机，可在设置页修改。配置结构和持久化版本未改变。
转速和时间是待硬件标定的初值，最高目标仍受 max_rpm 和全局安全限值约束。

## 按键与页面

| 输入 | 正常页面 | SETTINGS 页面 |
| --- | --- | --- |
| PC2 短按 | 依次选择待机、手动、自动、爆炒、清洁、睡眠；切换立即停机 | 提交合法草稿并回主页，配置应用保持停机 |
| PA0 短按 | 手动/自动/爆炒启停；故障页选择下一项故障 | 选择下一个参数 |
| PC3 / PC4 短按 | 手动目标增加/减少 | 参数增加/减少 |
| 编码器 | 调整手动目标，每 4 个计数为一档 | 调整当前参数 |
| PC3 长按 | 主页 → 传感器 → 环境 → 设置 → 故障 → 主页 | 离开设置页，放弃未提交草稿 |
| PA0 长按 | 立即停机；故障状态下申请安全复位 | 立即停机 |
| PC2 / PC4 长按 | 立即停机，取消延时关机 | 立即停机 |

进入设置页立即停机，编辑不会直接修改运行参数。可编辑手动目标、最高目标、关机延时、Kp/Ki/Kd、气体电压低/高阈值。
成功提交后显示 CONFIG:PENDING；停机且参数稳定至少 2 秒后，现有 Storage 流程保存，成功才显示 CONFIG:SAVED。
设置页未修改时直接返回；提交失败留在草稿页并发出警告音。

OLED 为现有 ASCII 字库，每行最多 21 字符，不引入中文点阵库。
传感器页显示气体 V、风速 M/S、预热/未校准状态、有效位和错误位；环境页显示温度 C、湿度 %、气压 PA。
气体、风速和温度保留 3 位小数，湿度保留 2 位小数；单位采用字库支持的大写字符。
无效、非有限或超过 500 ms 的采样显示 `--`，气体趋势不标为精确 ppm。
故障页解释堵转、超速、测速丢失、传感器未就绪、过温、PWM 输出、命令和控制时序故障；多故障可轮看，历史页读取已落盘的最近故障。

## 输出反馈

- 蜂鸣器由 UI 每 10 ms 调用 `Buzzer_Process()`；短按、模式切换、警告和故障提示均为有限次时序，不调用 HAL_Delay。
- 故障三短鸣优先于普通提示，同一故障不每个周期重复请求。
- 红灯：故障时以 500 ms 周期闪烁；绿灯：实际电机使能且无故障；蓝灯：正常 1 秒、睡眠 2 秒周期的 80 ms 心跳。
- OLED 每 100 ms 传输一个硬件页，8 页使用同一帧快照。页面/模式/故障变化重新从第 0 页刷新。
- OLED 通信失败会停止刷新；按键、LED、蜂鸣器和电机保护继续运行。
